Repositório unificado dedicado a centralizar exercícios, implementações e projetos desenvolvidos ao longo do curso de Ciência da Computação. O foco principal engloba **Algoritmos, Estruturas de Dados** e **programação de baixo nível**, consolidando a aplicação prática da teoria vista em sala de aula, utilizando exclusivamente a linguagem **C**.

##  Estrutura do Repositório

Os códigos estão organizados por temas e módulos de estudo. Abaixo está o índice das implementações:

| Diretório | Descrição |

| :--- | :--- |

| `AED-2/` | Projetos e exercícios da disciplina de Algoritmos e Estruturas de Dados 2. |

| `Estrutura-de-Dados-1/` | Fundamentos de gerenciamento de memória, ponteiros e estruturas lineares básicas. |

| `ListaLinearSimplesmenteEncadeada/` | Implementação e manipulação clássica de nós em listas encadeadas. |

| `filaDinamicaAlunos/` | Estruturas de dados baseadas em filas (FIFO) utilizando alocação dinâmica. |

| `exercicio-structfuncoes-c/` | Práticas de modularização: uso de structs, funções e passagem de parâmetros por valor e referência. |

| `ExerciciosAula/`, `Exercicios_19_11_24/`, `26_11_24/` | Resoluções de desafios práticos, listas de fixação e códigos desenvolvidos durante as aulas. |

##  Tecnologias e Tópicos Abordados

* **Linguagem Principal:** C
* **Conceitos Técnicos:**
  * Alocação Dinâmica de Memória (malloc, free)
  * Manipulação Avançada de Ponteiros
  * Tipos Abstratos de Dados (TAD)
  * Modularização de Código
